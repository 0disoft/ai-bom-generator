## Highlights

Preserve supplier, download location, summary and other unmapped preview evidence
in standard SPDX comments, alongside aiBom extension properties. This completes
the evidence-preserving bounded Core/Software/AI mapping introduced in v0.8.0.

## Compatibility

No CLI, config, Action input or existing preview behavior changes. The new
spdx-json-3.0.1 output retains additional redacted declared evidence as JSON text
in comment fields, without asserting verified suppliers or additional profiles.
Explicit BOM authorship and timestamp requirements are unchanged.

## Rollback

Use v0.7.1 with a previously supported format after removing the new spdx config
table and timestamp flag. Mutable v0 may move only after exact-version external
verification. Never rewrite immutable tags or delete published distributions.
