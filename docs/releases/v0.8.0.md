## Highlights

Add the opt-in spdx-json-3.0.1 exporter for a bounded Core/Software/AI mapping.
Require explicit BOM creator identity and creation time; support a CLI timestamp
override and deterministic UTC normalization. Reuse hash-verified upstream
validation resources and distinguish infrastructure failures from invalid BOMs.
Protect mutable Action channel promotion with an explicit remote lease.
Update Ruff, setuptools, setup-python and setup-uv after compatibility checks.

## Compatibility

Python 3.12 through 3.14 and existing spdx-ai/CycloneDX behavior remain supported.
The new format requires [spdx].creator_name, creator_type and created, with
--document-created optionally supplying or overriding only the timestamp.
These describe BOM authorship, not model creation or training provenance.
No host identity or current time is inferred. Additional evidence is preserved
as redacted JSON in standard comments; other SPDX profiles and legal compliance
are not claimed. Runtime export remains offline and Action inputs are unchanged.

## Rollback

Pin immutable v0.7.1 or install ai-bom-generator==0.7.1. Remove the new [spdx]
table and CLI flag and select a previously supported format before using it.
Repoint v0 only after exact-version external verification. Never rewrite
immutable tags or delete published package distributions.
