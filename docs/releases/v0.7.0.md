## Highlights

Artifact scanning now has a fixed enumeration ceiling and caller-selectable
lower budgets. New CLI flags enable or disable discovery without editing the
project config. Bash and PowerShell 7 completions are generated offline from
the executable CLI surface. Schema-accepted sensitive metadata keys produce
bounded, value-free warnings in either redaction mode.

## Compatibility

Python 3.12 through 3.14, existing GitHub Action inputs/outputs, exporter
identifiers, and output schemas are preserved. Config schema v1 gains optional
artifact limits. Projects exceeding the scan ceiling receive no partially
collected artifact set and a warning; `--warnings fail` can therefore fail
projects that previously scanned unbounded trees. Sensitive-key warnings can
also affect that policy. SPDX remains a partial preview, not upstream-conformant.
No product telemetry or automatic report upload is added.

## Rollback

Pin the immutable v0.6.1 release and remove the new optional limits and CLI
flags before running the older version. Repoint `v0` only after the exact
rollback target passes external smoke. Never rewrite immutable tags or delete
published distributions. Caller-owned generated reports retain their schemas.
