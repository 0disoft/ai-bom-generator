## Highlights

Update packaging, Ruff, CodeQL and the PyPI publishing Action while preserving
the reviewed lint rule baseline. Reconcile and classify public documentation,
refresh the supported security line, and add machine-verifiable documentation
drift checks. Add a CI-only upstream SPDX JSON Schema and SHACL gate covering
synthetic reference roundtrips, invalid mappings and expected preview rejection.

## Compatibility

Python 3.12 through 3.14, CLI flags, Action inputs/outputs, config schema v1 and
generated-output schemas are unchanged. SPDX output remains a partial preview:
the new gate does not make production output upstream-conformant. No runtime
network dependency, telemetry, automatic upload or target-directory mutation
is introduced. New major dependency proposals are not part of this release.

## Rollback

Pin immutable v0.7.0 or install ai-bom-generator==0.7.0. Repoint the mutable v0
channel only after external exact-version verification of that rollback target.
Do not rewrite immutable release tags or delete published distributions.
